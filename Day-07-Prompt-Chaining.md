# Day 7 - Prompt Chaining

## What is Prompt Chaining?

Prompt Chaining means solving one big task by breaking it into smaller prompts, where each prompt builds on the previous one.

## Why is it useful?

because solving one small task at a time produces better quality, fewer mistakes, and makes the work easier to edit and improve.

## Example

Imagine a client says:

"Build me an AI customer support chatbot."

A beginner might ask AI:

"Build the whole chatbot."

A professional would use Prompt Chaining like this:

Prompt 1

List the features the chatbot should have.

⬇️

Prompt 2

Create the conversation flow.

⬇️

Prompt 3

Write the welcome message.

⬇️

Prompt 4

Write answers for the top 20 customer questions.

⬇️

Prompt 5

Improve the chatbot to sound friendly and professional.

Each prompt builds on the previous one.
